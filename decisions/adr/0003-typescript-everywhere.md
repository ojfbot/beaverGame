# ADR-0003: TypeScript everywhere; Python only as a build artifact

Date: 2026-04
Status: Accepted
OKR: 2026-Q2 / O2 / KR1 (assistant-centric architecture)
Commands affected: /scaffold, /validate
Repos affected: beaverGame, asset-foundry

---

## Context

The cluster convention (cv-builder, TripPlanner, landing) is TypeScript end-to-end. The asset pipeline involves Blender bpy scripts, which must be Python because that's the only language the Blender API speaks. We want a single mental model for source code without pretending Python doesn't exist.

## Decision

All hand-authored source code is TypeScript. Blender bpy scripts are treated as **build artifacts**, generated by the AssetSculptor sub-agent and never edited by hand. They live under `asset-foundry/dist/scripts/` (gitignored) and are regenerated each pipeline run.

## Consequences

### Gains
- One tsconfig idiom, one linter, one test runner across both repos.
- Blender API drift surfaces in one place — the script generator — rather than scattered Python source files.
- Reviewers don't need to read Python to understand a generated asset; the manifest entry and the script's stdout JSON tell the whole story.

### Costs
- Debugging a failed bpy script requires reading generated code. Mitigation: the AssetSculptor must emit comments tagging which manifest field drove which line.
- We forfeit Python's NumPy ergonomics for any future procedural geometry math; if needed we'll write that math in TypeScript and emit it as bpy.

### Neutral
- Blender CLI invocations, JSON parsing of stdout, and TCP MCP bridge all happen from TypeScript.

## Alternatives considered

| Alternative | Why rejected |
|-------------|--------------|
| Mixed source (TS for orchestrator, Python for sculpt logic by hand) | Violates the assistant-centric architecture pillar — two source languages, two conventions. |
| Python everywhere (drop TS for asset-foundry) | Breaks cluster convention and loses the LangGraph TS ecosystem we already use in cv-builder. |
| Rust for orchestrator | Overkill; LangGraph TS is the established cluster pattern. |
